# expressRNA

**A computational platform for post-transcriptional RNA regulation.**

expressRNA takes you from raw sequencing data to biological insight: upload bulk RNA-seq experiments and run differential gene expression, alternative splicing and other analyses automatically. It also supports 3′-end sequencing data, quantifying polyA site usage against a curated reference atlas for differential Alternative Polyadenylation (APA) analysis. Results are interactive, shareable, and directly comparable across experiments.

🔗 **[expressRNA.org](https://expressrna.org)**

This repository is used for tracking public **ideas and issues** — bug reports, feature requests, and discussion are all welcome.
