# expressRNA

**A computational platform for post-transcriptional RNA regulation.**

expressRNA takes you from raw sequencing data to biological insight: upload 3′-end sequencing experiments, quantify polyA site usage against a curated reference atlas, and run differential Alternative Polyadenylation (APA), splicing, and expression analyses — all interactive, shareable, and directly comparable across experiments.

🔗 **[expressRNA.org](https://expressrna.org)**

This repository is used for tracking public **ideas and issues** — bug reports, feature requests, and discussion are all welcome.
